# 📊 Sales Data Analysis Dashboard

## 📌 Project Overview
This project analyzes supermarket sales data using Python to uncover valuable business insights. The analysis focuses on sales performance, customer behavior, product trends, and branch-wise performance through exploratory data analysis (EDA) and data visualization.
---

## 📂 Dataset
- **Dataset:** Supermarket Sales Dataset
- **Records:** 1,000+ sales transactions
- **Features:** 17 columns including:
  - Invoice ID
  - Branch
  - City
  - Customer Type
  - Gender
  - Product Line
  - Unit Price
  - Quantity
  - Tax
  - Total Sales
  - Date & Time
  - Payment Method
  - Gross Income
  - Customer Rating

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🎯 Project Objectives

- Clean and preprocess sales data.
- Perform Exploratory Data Analysis (EDA).
- Identify sales trends and customer purchasing behavior.
- Analyze product performance across branches.
- Generate business KPIs.
- Create meaningful visualizations for decision-making.

---

## 🔄 Workflow

1. Data Loading
2. Data Cleaning
3. Missing Value Check
4. Duplicate Removal
5. Feature Engineering
6. Exploratory Data Analysis (EDA)
7. KPI Calculation
8. Data Visualization
9. Business Insights
10. Conclusion

---

## 📈 Key Findings

- Branch-wise sales performance was compared.
- Food & Beverages generated the highest revenue.
- Customer ratings were analyzed across branches.
- E-wallet and Cash were among the most preferred payment methods.
- Sales trends varied across different times of the day.
- Product line performance highlighted top-selling categories.
